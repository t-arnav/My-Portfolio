# 🌐 My Portfolio Website

This repository contains the source code for my **personal portfolio website** built to showcase my projects, technical skills, certifications, and professional experience as a Computer Science student and software developer.

The portfolio serves as a central place where recruiters, collaborators, and developers can learn more about my work and connect with me.

## ⚙️ Installation & Setup

Clone the repository:
git clone https://github.com/t-arnav/My-Portfolio.git

Navigate to the project folder:
cd My-Portfolio

Install dependencies:
npm install

Run the development server:
npm start

The application will run on:
http://localhost:3000
